# Security Policy

## Security Maintainer

sysdirs security is maintained by **Brandon Sneed** ([@bsneed](https://github.com/bsneed)),
the crate's owner on [crates.io](https://crates.io/crates/sysdirs).

## Supported Versions

Security fixes are released for the latest minor version only.

| Version | Supported |
|---------|-----------|
| 0.9.x   | Yes       |
| < 0.9   | No        |

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues.**

Email **brandon@redf.net** with the subject line `[sysdirs security]`. Please include:

- The affected version(s) and platform(s)
- A description of the issue and its impact
- Steps or code to reproduce it, if available

### What to expect

- Acknowledgement within 3 business days.
- An initial assessment within 7 days, including whether the report is accepted.
- For accepted reports, a fix released as a patch version, followed by a
  [RustSec](https://rustsec.org) advisory where appropriate.

Reporters are credited in the release notes unless they ask not to be.
Please allow a reasonable window for a fix to ship before disclosing publicly.
